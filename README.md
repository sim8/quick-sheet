# Quick Sheet

A React + TypeScript spreadsheet starter with a 100 × 100 editable grid.

```sh
npm install
npm run dev
```

Each cell stores its own value in React state. Values reset on page reload.
Column headers (A–CV) and row numbers stay visible while scrolling. Tab moves
between cells; Enter and Shift+Enter move down and up within a column.

Run `npm run build` to type-check and produce the production app in `dist`.
